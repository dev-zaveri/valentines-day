# 🚀 Quick Start Guide - Valentine's Day DVD Website

## Step-by-Step Setup (5 minutes)

### 1. Add Your Content 📁

**Add Images** (Required):
```
valentine-dvd-menu/images/
├── scene-1.jpg
├── scene-2.jpg
├── scene-3.jpg
├── scene-4.jpg
├── photo-1.jpg
├── photo-2.jpg
├── photo-3.jpg
├── photo-4.jpg
├── photo-5.jpg
└── photo-6.jpg
```

**Add Music** (Required):
```
valentine-dvd-menu/audio/
├── menu-music.mp3
├── play-music.mp3
├── scenes-music.mp3
├── gallery-music.mp3
└── close-music.mp3
```

**Add Video** (Required):
```
valentine-dvd-menu/videos/
└── valentine-video.mp4
```

### 2. Test Locally 🧪

1. Double-click `index.html` to open in your browser
2. Navigate through all pages to test functionality
3. Make sure images, music, and video load correctly

### 3. Deploy to Netlify 🌐

**Option A - Drag & Drop (Easiest)**:
1. Go to [netlify.com/drop](https://app.netlify.com/drop)
2. Drag the entire `valentine-dvd-menu` folder onto the page
3. Wait for upload to complete (1-2 minutes)
4. Copy your site URL: `https://yoursite.netlify.app`
5. Share with your Valentine! 💕

**Option B - GitHub + Netlify**:
1. Create a new repository on GitHub
2. Upload the `valentine-dvd-menu` folder
3. Go to [netlify.com](https://www.netlify.com)
4. Click "New site from Git"
5. Select your repository
6. Click "Deploy site"

### 4. Customize (Optional) 🎨

**Change Site Name**:
- In Netlify: Site Settings → Domain Management → Change Site Name
- Example: `my-valentine-2025.netlify.app`

**Add Custom Domain**:
- Buy a domain (e.g., from Namecheap, Google Domains)
- In Netlify: Add custom domain
- Follow DNS setup instructions

**Edit Colors/Text**:
- Colors: Edit `css/main.css` (look for CSS variables at the top)
- Text: Edit HTML files directly
- Scene titles: Edit `scenes.html`
- Error message: Edit `close.html`

## ⚡ Pro Tips

1. **Compress your video** to under 50MB for faster loading
2. **Optimize images** using TinyPNG or similar tools
3. **Test on mobile** before sharing
4. **Add a custom icon** (create `favicon.ico` in root folder)
5. **Preview first** - click through everything before sending

## 🆘 Need Help?

**Common Issues**:

- **Images not loading?** → Check filenames match exactly (case-sensitive)
- **Music not playing?** → Click anywhere on the page first (browser requirement)
- **Video too large?** → Compress using HandBrake or CloudConvert
- **Site not updating?** → Clear browser cache or wait 1 minute for Netlify

**Still stuck?** Check the main README.md for detailed troubleshooting.
