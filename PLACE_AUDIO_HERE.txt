# Audio Folder

Place your music files here with these exact filenames:

## Required Music Files (3 files needed)
- menu-music.mp3 (Background music for main menu, scenes, and gallery)
- play-music.mp3 (Background music for video page - optional, can use menu-music if you want)
- close-music.mp3 (Background music for closing page - optional)

**You only NEED menu-music.mp3 - the others are optional!**

## Tips:
- All files must be MP3 format
- Music will loop automatically on each page
- Recommended length: 1-3 minutes (since it loops)
- Keep file sizes reasonable (under 5MB per file)
- Music auto-plays after user's first interaction (browser requirement)
- Volume automatically adjusts when video plays

## Optional:
- You can use the same music file for multiple pages
- Just copy/rename the file to match the required filenames
- For example, if you want the same music everywhere:
  - Copy your-song.mp3 five times with different names
